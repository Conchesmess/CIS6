Course Description

CIS6 is a year-long computing and engineering course. Students build skills in robotics, Python programming, physical computing, and interactive game design before completing a student-driven capstone project.

Learning Goals

  • Apply computational thinking to design and debug working systems.
  • Move from visual coding to text-based coding in Python.
  • Build and test programs that connect software and hardware.
  • Plan, build, document, and present a complete technical project.

Materials

  • Lego Spike Prime kits
  • Computers with Lego Education software and Python tools
  • Raspberry Pi Pico and/or Raspberry Pi 4 kits
  • Godot game engine (for game unit)

Grading Framework (Draft)

  • 40% Projects and performance tasks
  • 25% Labs and code check-ins
  • 20% Quizzes and skill checks
  • 15% Reflection and collaboration evidence

Major Units

  1. Term 1 Unit: Spike Prime with Blocks
  2. Term 2 Unit: Spike Prime with Python
  3. Term 3 Unit: Raspberry Pi + Godot
  4. Term 4 Unit: Final Project
