Course Snapshot

  • Grade Level: 11th grade (3rd year high school students)
  • Course Length: Full year, 4 terms
  • Primary Themes: Robotics, Python, Physical Computing, Game Development, Capstone

Term Breakdown

  1. Term 1: Lego Spike Prime with block coding fundamentals and design process.
  2. Term 2: Writing Code in Python
    1. Python Turtle: Use python code to draw a scene.
    2. Python Spike Prime: Use Python to code the Spike Prime Robot
  3. Term 3:
    1. Raspberry Pi (Pico or Pi 4)
    2. PyGame supported by Claude Code
    3. Machine Learning if time
  4. Term 4: Student-directed final project with milestones and public showcase.
