Course Snapshot

  • Grade Level: 11th grade (3rd year high school students)
  • Course Length: Full year, 4 terms
  • Primary Themes: Robotics, Python, Physical Computing, Game Development, Capstone

Term Breakdown

  1. Term 1: Lego Spike Prime with block coding fundamentals and design process.
  2. Terms 2–3: Writing Code in Python
    1. Python Turtle — Use Python code to draw a scene. Covers variables, loops, and functions.
    2. Spike Prime Python — Use Python to code the Spike Prime robot.
    3. Coding with AI — Use AI tools to design, build, and iterate on a coding project.
  3. Term 4: Student-directed final project with milestones and public showcase.
