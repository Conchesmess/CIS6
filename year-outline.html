Course Snapshot

  • Grade Level: 11th grade (3rd year high school students)
  • Course Length: Full year, 4 terms
  • Primary Themes: Robotics, Python, Physical Computing, Game Development, Capstone

Term Breakdown

  1. Term 1: Lego Spike Prime with block coding fundamentals and design process.
  2. Term 2: Python transition on Spike Prime, algorithmic thinking, code structure.
  3. Term 3: Raspberry Pi (Pico or Pi 4) and Godot game development unit.
  4. Term 4: Student-directed final project with milestones and public showcase.

Assessment Pattern

  • Weekly skill checks and mini challenges
  • Project artifacts and milestone demonstrations
  • Reflection journals and peer feedback
