Intro to Python using the Turtle

Lesson 1: Getting Started

  1. Set up Visual Studio Code
  2. Draw a red box filled with yellow
  3. Draw a star outlined with the color rgb(255,255,0) and filled with rgb(0,255,255)

Lesson 2: The Turtle Screen

Understanding the canvas before drawing on it. Concepts covered:

  • screen.setup(width, height) — sets the window size in pixels.
  • Coordinate system — (0, 0) is the center; x increases right, y increases up.
  • goto(x, y) — moves the turtle directly to a coordinate.
  • penup() / pendown() — lifts and lowers the pen so the turtle can move without drawing.
  • setheading(angle) — points the turtle in a compass direction (0 = right, 90 = up, 180 = left, 270 = down).

Lesson 3: Loops

Introduces for loops and range(). Students draw a solid 255×255 square by looping 255 times, drawing one vertical line per iteration and stepping one pixel to the right each time. tracer(0) and screen.update() are introduced to make the drawing appear instantly.

Why draw 255 separate lines instead of using begin_fill()? Because each line can be a different color — the payoff comes in Lesson 4.

Lesson 4: Gradients

Introduces variables by giving the three color channels their own names: r = 255, g = 255, b = 0 (yellow). Students call pencolor(r, g, b) inside the Lesson 3 loop and subtract 1 from g each iteration so the color shifts from yellow to red across the square.

Lesson 5: Functions

Introduces defining and calling functions with parameters, plus the random module.

  1. Write a function bird(radius) that draws one bird shape from two arcs using turtle.circle().
  2. Write a function birds(num_birds) that loops num_birds times, moving to a random location and calling bird() with a random radius each time.

Lesson 6: Draw a Sun

  1. Draw a dot so that half the dot extends off the top of the screen.
  2. Sun Rays: Starting at the middle of the sun dot, turn the turtle using setheading(0) and go forward then backwards. Then add some amount to the heading and go forward and back again. Do this as many times as needed to make rays coming out of the sun. Extra credit for changing colors.
  3. Gradient: Start by drawing a large dot then, in a loop, reduce the size of the dot and slightly change the color of the dot and draw the new dot on top of the last one.

Lesson 7: Draw a Scene

Combine ALL of the previous lessons (gradient background for a sky, birds, sun) and at least two other elements (e.g., grass, flowers, clouds, etc).
